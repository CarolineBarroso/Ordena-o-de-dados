# Ordenação-de-dados
Neste projeto, desenvolvi um programa para trabalhar com ordenação de dados e manipulação de arquivos. A proposta foi criar um arquivo com números desordenados, realizar a leitura desses dados e permitir a escolha entre diferentes formas de ordenação: Bubble Sort, Insertion Sort, Selection Sort, Merge Sort e Quick Sort.
— Algoritmos de Ordenação em C

📌 Sobre o projeto

Este projeto foi desenvolvido em linguagem C com o objetivo de aplicar conceitos de algoritmos de ordenação e manipulação de arquivos.

O programa permite inserir valores numéricos desordenados, armazená-los em um arquivo .txt, realizar a leitura desses dados e escolher diferentes algoritmos para organizar os valores em ordem crescente.

⚙️ Funcionalidades

* Inserção de valores numéricos;
* Criação e leitura de arquivo dados.txt;
* Escolha do algoritmo de ordenação;
* Ordenação dos números em ordem crescente;
* Salvamento do resultado em resultado.txt;
* Possibilidade de testar diferentes algoritmos no mesmo programa.

🔢 Algoritmos utilizados

1. Bubble Sort

Compara elementos vizinhos e realiza uma troca quando eles estão fora de ordem.

2. Insertion Sort

Percorre os elementos e insere cada valor na posição correta entre os elementos que já foram ordenados.

3. Selection Sort

Procura o menor elemento do vetor e o coloca na posição correta.

4. Merge Sort

Divide o vetor em partes menores, ordena essas partes e depois realiza a junção dos elementos em ordem.

5. Quick Sort

Utiliza um elemento como pivô para separar os valores menores e maiores, repetindo o processo até ordenar o vetor.

▶️ Como executar

1. Compile o arquivo main.c utilizando um compilador C.
2. Execute o programa.
3. Informe a quantidade de números.
4. Digite os valores.
5. Escolha um dos algoritmos de ordenação.
6. Confira o resultado no terminal.
7. O resultado também será salvo no arquivo resultado.txt.
